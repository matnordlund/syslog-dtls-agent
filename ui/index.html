CONFIGURATION

Build your connection.

Settings apply on the next start. Stop the relay to make changes.

01

Local listener

One RFC 5424 message per UDP datagram.

IP

Source access

Choose which source IPs may send logs. Changes apply on the next relay start.

Add exact IPv4 or IPv6 addresses. Source ports are ignored. Hostnames and CIDR ranges are not supported.

    The allowlist is empty. In allowlist mode, all sources will be blocked.

    UDP source IPs are not authenticated identities. Use network controls where sender authentication is required.

    02

    Remote collector

    Encrypted forwarding over DTLS 1.2 / UDP.

    03

    Certificates & trust

    PEM files are read by the Rust backend. Private keys never enter this interface.

    04

    Buffering & transport

    Both queue limits include the message currently being written.

    A frame must fit the negotiated DTLS payload budget. Larger messages are dropped whole, never truncated. Rate limiting is not network congestion control.

    05

    HTTP listener

    Save the configuration, then restart the agent process to apply these settings. Stopping and starting the relay does not restart HTTP.

    Without OIDC, HTTP has no authentication. A network-facing IP exposes agent controls to other devices. Use loopback for local access or restrict access with a firewall. These settings apply to the headless agent; the desktop app does not start an HTTP listener. A command-line --http-listen override takes precedence.

    06

    OpenID Connect

    Protect the HTTP interface with your identity provider and a required group. Save and restart the agent process to apply changes.

    When enabled, login protects all HTTP access, including loopback. Sessions expire within one hour or at ID-token expiry. HTTP is supported; HTTPS protects credentials and sessions in transit. The desktop interface continues to use native access.

    OIDC client secrets are saved in the configuration file.
