# Third-party dependencies

The Rust and JavaScript dependencies are identified by `Cargo.lock` and `package-lock.json`.

- OpenSSL 3: Apache License 2.0, https://www.openssl.org/source/license.html
- Rust OpenSSL bindings: Apache License 2.0, https://github.com/rust-openssl/rust-openssl
- Tauri: MIT or Apache License 2.0, https://github.com/tauri-apps/tauri

These are the principal runtime components, not an exhaustive transitive license inventory. Source packages contain their respective license texts. Distributors must include applicable license/notice texts for the precise dependencies and native libraries they ship. Vendored OpenSSL is linked into this application's builds by default.

The application icon and desktop assets are original project assets covered by the project MIT license. No externally hosted fonts, images, or scripts are loaded.
